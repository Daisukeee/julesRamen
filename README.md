# Ramen Image Analyzer

This web application analyzes uploaded ramen images using AI (Gemini) to identify the ramen shop and display its name and location.

## How to Use

1.  Open the `index.html` file in your web browser.
2.  Click the "Choose File" button to select an image of ramen.
3.  Once the image is previewed, click the "Analyze Ramen" button.
4.  The application will display the identified ramen shop's name and location.

## Current Status

- Basic frontend structure is in place.
- Image upload and preview functionality is working.
- AI analysis is currently using mock data.
- Shop identification is based on mock data.
